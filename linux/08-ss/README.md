# 实验 08：ss —— 端口、连接和进程归属

> 🎯 **目标**：用 ss 确认端口是否监听、监听在哪个地址、哪个进程持有它。

~~~bash
make
./ss_demo &
pid=$!
ss -ltn
ss -ltnp | grep 18080
ss -tan | grep 18080
kill "$pid"
~~~

| 选项 | 含义 |
|------|------|
| -l | 只看监听 socket |
| -t | TCP |
| -u | UDP |
| -n | 不解析名称，保留端口数字 |
| -p | 显示进程（可能需要 sudo） |
| -a | 包含非监听连接 |

127.0.0.1:18080 只接受本机连接；0.0.0.0:18080 才会监听所有 IPv4 地址。排查“服务启动了却访问不到”时必须区分二者。

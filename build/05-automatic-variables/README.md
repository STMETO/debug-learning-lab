# 实验 05：自动变量 —— 规则中的目标和依赖

> 🎯 **目标**：准确理解 `$@`、`$<`、`$^`、`$?`。

| 变量 | 含义 | 在 `app: main.o helper.o` 中 |
|------|------|------------------------------|
| `$@` | 当前目标 | `app` |
| `$<` | 第一个依赖 | `main.o` |
| `$^` | 所有依赖，去重 | `main.o helper.o` |
| `$?` | 比目标新的依赖 | 取决于本次修改 |
| `$*` | 模式规则中 `%` 匹配部分 | 实验 08 使用 |

编译规则：

```makefile
main.o: main.c
	$(CC) $(CFLAGS) -c -o $@ $<
```

展开为：

```bash
gcc -g -Wall -Wextra -c -o main.o main.c
```

链接规则：

```makefile
app: main.o helper.o
	$(CC) -o $@ $^
```

执行 `make`，再 `touch helper.c && make`，观察 `$?`。

Makefile 中 `$` 有特殊意义。要把一个 `$` 传给 shell，通常写 `$$`。

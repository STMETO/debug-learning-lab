# 实验 05：tcpdump 基础 —— 先把名字和数量控制住

> 🎯 **目标**：在 loopback 上抓一小段可读 TCP 流量。

终端 A：

~~~bash
sudo tcpdump -ni lo -vv -c 10 tcp
~~~

终端 B：

~~~bash
nc -vz 127.0.0.1 1
~~~

| 选项 | 含义 |
|------|------|
| -i lo | 指定 loopback，避免猜接口 |
| -n | 不做 DNS/端口名解析，避免输出污染 |
| -vv | 显示更多协议字段 |
| -c 10 | 抓够即退出，避免无限运行 |

即使连接失败，你仍可能看到 SYN 和 RST；这正是“拒绝”比“超时”更有诊断价值的原因。
